# Projeto: Data Science & Pontos (DS & Points)

Este projeto tem como objetivo realizar a análise, modelagem e exploração de dados do ecossistema de pontos do canal **TeoMeWhy**. A partir de dados reais e atualizados, desenvolvemos soluções para entender o engajamento da comunidade e otimizar a gestão de pontuação.

## 🎯 Objetivo
Desenvolver uma solução analítica capaz de processar os logs de interação, calcular pontuações e extrair insights estratégicos sobre o comportamento dos membros da comunidade.

## 🛠 Tecnologias Utilizadas
* **Linguagem:** Python
* **Manipulação de Dados:** Pandas, NumPy
* **Visualização:** Matplotlib, Seaborn, Plotly
* **Controle de Versão:** Git & GitHub
* **Ambiente:** Jupyter Notebooks / VS Code

## 📊 Estrutura do Projeto
- `data/`: Contém o dataset (utilize o link do Kaggle do Téo Calvo para atualizar os dados).
- `notebooks/`: Análises exploratórias (EDA) e protótipos de modelagem.
- `src/`: Scripts de processamento e automação.
- `reports/`: Relatórios e dashboards gerados.

## 🚀 Como Executar
1. Clone este repositório:
   `git clone https://github.com/FernandaMoura96/Points-Ecosystem-Insights`
2. Instale as dependências:
   `pip install -r requirements.txt`
3. Baixe o dataset atualizado no [Kaggle do Téo Calvo](https://www.kaggle.com/datasets/teocalvo/teomewhy-loyalty-system).
4. Coloque o arquivo na pasta `/data` e execute os notebooks na sequência sugerida.
